## Creational design patterns
Creational design patterns address how objects are created. The main patterns are:
* **Abstract Factory**: Creates families of related objects without specifying their concrete classes.
* **Factory Method**: Lets subclasses define which object to create.
* **Builder**: Separates object construction from its representation.
* **Pool**: Manages reusable objects to avoid costly creations.
* **Prototype**: Creates new objects by copying an existing one.
* **Singleton**: Ensures a class has only one instance.
