# Stream-Based Architecture

## Description
Stream-based architecture processes data as continuous streams of events, rather than in batches. It’s commonly used for real-time data pipelines (Kafka, RabbitMQ, etc.) or event sourcing.

## Pros
**Real-time processing**: Enables immediate responses to incoming data.  

**Fault tolerance**: Streams can be replayed for error recovery.  

**Scalability**: Can handle large amounts of data efficiently.
